项目背景

实现人员管理、风险监控、评论监控等系统的可视化与自动化：把开发人员入场离场、服务管理、建单告警、风险管理等分散动作，统一收敛到一套带数据看板的运维平台中，降低人工核对成本，提升异常响应速度。

技术栈

Vue ECharts MVT Element UI Oracle PostgreSQL

核心职责

01

Vue 前端开发

开发人员入场离场、服务管理、建单告警、风险管理、数据看板等模块的前端实现，基于 MVT 架构与 Element UI 组件库搭建。

02

ECharts 可视化

实现报表、流程图、饼图等交互图表，支持点击钻取下钻明细，让运维指标一眼可见、可溯源。

03

数据库迁移改造

完成 Oracle → PostgreSQL、ES5 → ES7 的代码改造，兼顾存量 SQL 与查询语法，保障系统稳定迁移、平滑过渡。
