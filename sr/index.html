图像超分算法合并框架 · 代码演示

下方展示 ESRGAN 原始仓库（sr/ESRGAN）的代码与目录层级 —— 它是超分框架合并的参考源之一。点击左侧文件树浏览目录，点击文件后在右侧查看源码内容。

合并范式： YAML 配置驱动 + Registry 注册表 + BaseArch / BaseModel 继承。 训练/推理只写一个入口（train.py / inference.py），不同算法靠 YAML 里 model 与 network_g / network_d 的 type 与参数切换； RRDBNet / SRVGGNetCompact / 判别器 等网络经注册表统一实例化；SR / ESRGAN / RealESRGAN 三类模型以 SRModel → ESRGANModel → RealESRGANModel 继承链复用公共逻辑。 三仓库原始代码保留于 BasicSR/、ESRGAN/、Real-ESRGAN/ 作为参考，合并后的唯一实现位于 sr_framework/。
