项目背景

平台定位

面向运维场景的可视化与自动化平台，覆盖人员管理、风险监控、评论监控等系统，将日常运维动作沉淀为标准化看板与告警流程，降低人工核对成本，提升异常响应速度。

痛点

开发人员入场离场、服务管理、建单告警、风险管理等动作分散，依赖人工核对，异常响应慢、易遗漏。

目标

用一套带数据看板的运维平台统一收敛上述动作，让关键指标一眼可见、可溯源、可钻取。

价值

降低人工核对成本，提升异常响应速度与系统稳定性（含 Oracle→PG、ES5→ES7 平滑迁移）。

技术栈

技术选型

前端可视化与后端数据层协同，兼顾存量系统迁移改造。

核心职责

我的工作

三方面落地：前端开发、可视化交互、数据库迁移改造。

01

Vue 前端开发

开发人员入场离场、服务管理、建单告警、风险管理、数据看板等模块的前端实现，基于 MVT 架构与 Element UI 组件库搭建。

02

ECharts 可视化

实现报表、流程图、饼图等交互图表，支持点击钻取下钻明细，让运维指标一眼可见、可溯源。

03

数据库迁移改造

完成 Oracle → PostgreSQL、ES5 → ES7 的代码改造，兼顾存量 SQL 与查询语法，保障系统稳定迁移、平滑过渡。
